# Homebrew tap for ctx-guard

```bash
brew install ctx-guard/tap/ctx-guard
ctx-guard install
```

Homebrew installs the files only; `ctx-guard install` sets up your agents. See the [main repo](https://github.com/viktor-tapovski/ctx-guard).

`Formula/ctx-guard.rb` is updated automatically by each ctx-guard release. Report issues in the [main repo](https://github.com/viktor-tapovski/ctx-guard/issues).
